\# Beecrowd 1002 - Área do Círculo



\## Descrição



Este programa resolve o problema 1002 do Beecrowd.



\## Tecnologias utilizadas



\- Java

\- NetBeans

\- Maven



\## Entrada



A entrada contém um valor de ponto flutuante que representa o raio do círculo.



\## Saída



O programa apresenta a área do círculo no formato:



\*\*A = resultado\*\*
